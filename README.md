# TaskFlow Lite

TaskFlow Lite is a responsive task management web application built using HTML, CSS, and Vanilla JavaScript.

## Features

- Add tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks (All / Active / Completed)
- localStorage support for data persistence
- Responsive modern UI

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- localStorage

## Project Structure

taskflow-lite/
├── index.html
├── app.js
├── styles/
├── modules/
└── README.md

## How to Run

1. Open the project in VS Code
2. Install Live Server extension
3. Right click `index.html`
4. Click "Open with Live Server"
